매출 대시보드

매일 들어오는 월 누적 실적 파일을 쌓아 두고, 스냅샷 간 차분으로 일간 매출을 복원해 보여주는 지점 단위 영업 대시보드.

대시보드 열기 →

비밀번호가 필요합니다. 담당자에게 문의하세요.
담당자 PC가 꺼져 있으면 접속되지 않습니다.

대시보드는 이 페이지가 아니라 담당자 PC에서 돌아갑니다.
실적 데이터에는 설계사 개인정보가 들어 있어 공개 호스팅에 올리지 않습니다. 위 버튼은 비밀번호로 보호된 별도 주소로 연결됩니다.

어떻게 동작하나

데이터는 담당자 PC를 떠나지 않습니다. 외부 DB에 아무것도 업로드하지 않고, 터널은 바깥에서 그 PC까지 오는 길만 뚫어줍니다.

브라우저 → 터널(HTTPS) → 담당자 PC → 로컬 실적 파일 → 렌더 → 응답

접속 보호

  • 비로그인 요청은 전부 로그인 화면으로 돌려보냄
  • 세션 쿠키는 httpOnly + HMAC 서명 — 위조·만료 토큰 거부
  • 로그인 시도 제한으로 무차별 대입 차단
  • 실적 파일은 웹에서 직접 접근 불가한 경로에 보관

기술 구성

ETL은 Python (pyxlsb, openpyxl, msoffcrypto-tool), 화면은 Next.js · TypeScript · Tailwind · shadcn/ui · Recharts.

설치와 운영 방법은 저장소 README에 정리돼 있습니다. 실적 데이터·목표·비밀번호는 저장소에 포함되어 있지 않습니다.

이 페이지는 소스 저장소 안내용이며 실적 데이터를 포함하지 않습니다.
